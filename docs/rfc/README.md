# RFCs

EN: Port-trait changes (ModelRouter / SandboxProvider / MemoryBackend /
ToolProvider) and wire-schema breaking changes require an RFC here:
motivation, alternatives, wire compatibility, migration. Two maintainer
approvals. No RFC, no change.
The fourth port (`ToolProvider` + `ActionPolicy`) landed via
[RFC 0002](0002-tool-execution-port.md) — recorded with an honest
single-maintainer approval and an open invitation for external review.
Any FURTHER port trait or breaking change still starts with an RFC here.

CR: 端口 trait 变更与 wire 破坏性变更须先立 RFC（动机/备选/wire 兼容/迁移），
两名维护者批准。无 RFC 不变更。第四端口（`ToolProvider` + `ActionPolicy`）
已经 [RFC 0002](0002-tool-execution-port.md) 落地——如实标注单维护者批准并公开
征集外部评审。此后任何新端口或破坏性变更仍从这里的 RFC 起步。
